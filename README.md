# datasets-prj1
## Origen de los Datos y Citación

El conjunto de datos utilizado en este proyecto proviene de **Kaggle**:

* **Dataset:** [Impact of Ai on Students](https://www.kaggle.com/datasets/laveshjadon/ai-impact-on-students "Impact of Ai on Students - Kaggle")
* **Autor:** [Lavesh Jadon](https://www.kaggle.com/laveshjadon "laveshjadon - Kaggle")
* **Licencia:** CC0: Public Domain (Dominio Público)

*Nota: Este conjunto de datos cuenta con 50,000 registros que simulan de manera algorítmica las tendencias y el impacto de las herramientas de inteligencia artificial generativa en el entorno académico y el bienestar de los estudiantes.*
